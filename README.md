# tung-helper（出勤小幫手）

操作醫院「出勤系統」(OFCMB.EXE) 的 Windows 小工具集。介面比照 Windows 11 設定（Fluent 風格，跟著系統深淺色與強調色），外觀與班別規則沿用 [tungwifi](https://github.com/Mux1r/tungwifi)。

## 功能

- **值班加班申請**：從排班表找出值班日，自動到「加班申請」逐筆填寫並存檔，有執行、暫停／繼續、停止、只預覽。
  - 值班日：當天是 9076，且隔天是 906 或 908
  - 每個值班日申請兩筆：值班當天 17:30–24:00、值班隔天 00:00–08:00（類別「1:領錢」、理由「值班」，可在「設定」頁改）
  - 先用同一組時間把所有「值班當天」送完，再改時間送「值班隔天」；送出前會核對欄位，不符就跳過不送
  - 遇到「當天排班尚未核准」會整個停下
- **班表**：讀取「排班申請」畫面顯示的月份，讀完可一鍵匯出 `班表_年-月.csv` 到自己的「下載」資料夾。

## 使用

第一次使用：下載後在資料夾裡執行一次，建立捷徑（加 `-Desktop` 也會放一份到桌面；資料夾搬家後再執行一次）：

```powershell
powershell -ExecutionPolicy Bypass -File .\make-shortcut.ps1 -Desktop
```

之後：

1. 開啟並登入出勤系統，視窗保持最大化。
2. 點兩下「出勤小幫手」捷徑。捷徑透過 `conhost --headless` 啟動，不會多開 PowerShell 視窗。
3. 執行中請勿動滑鼠鍵盤；暫停、停止會在目前這一筆做完後生效。

需求：Windows 10/11、Windows PowerShell 5.1（內建）。不需要另外安裝任何東西，也不需要 AI。

## 更新

「關於與更新」頁（做法比照 tungwifi）：

- **檢查更新**：列出 GitHub 上比本機新的每一筆改動；開啟程式時也會在背景查一次，有新版會在選單上加個點。
- **立即更新**：下載最新版，只覆蓋程式檔；新版只要有一支腳本語法錯誤就整批不裝。更新前會先備份，裝完自動重開程式。
- **還原上一版**：退回更新前的版本，且這一版不會再被自動裝回來。
- **每天自動更新**：開關打開會建立排程 `tung-helper-AutoUpdate`，每天 09:00 檢查並安裝（電腦沒開會補做）；值班加班申請進行中會等它做完。

版本、備份、更新紀錄放在 `update\`，不進 GitHub。也可以直接執行：

```powershell
powershell -ExecutionPolicy Bypass -File .\update.ps1 -Apply      # 立即更新
powershell -ExecutionPolicy Bypass -File .\update.ps1 -Rollback   # 還原上一版
powershell -ExecutionPolicy Bypass -File .\update.ps1 -Install    # 每天自動更新（-Uninstall 移除）
```

## 多人共用

- 程式資料夾不寫入任何個人資料：班表、設定只放在記憶體，關閉視窗後全部清除。
- 背景工作的進度檔放在 `%TEMP%\出勤小幫手-<PID>`，關閉時刪除。
- 班表只有按「匯出」時才存到使用者自己的「下載」資料夾。
- 程式操作的是出勤系統**目前登入的帳號**，換人使用時出勤系統也要換人登入。

## 怎麼做到的

- 讀班表：在排班表格雙擊第一格，之後每格 `Ctrl+C` 讀值、`Enter` 跳下一格，最後按 `Esc` 離開編輯（不修改班表）。
- 填表單：用 UI Automation 找到欄位，以 Windows 訊息讀寫（`WM_GETTEXT`、`WM_SETTEXT`、`WM_CHAR`、`CB_SETCURSEL`），不經鍵盤打字，所以不受注音輸入法影響；不靠截圖辨識。
- 系統地區設定可能使用民國曆，日期一律自行以數字格式化。

## 檔案

| 路徑 | 用途 |
| --- | --- |
| `出勤小幫手.ps1` | 主視窗：左側選單、背景工作管理 |
| `ui\fluent.ps1` | Fluent 外觀元件與色票 |
| `lib\ofcmb.ps1` | 操作出勤系統的共用函式 |
| `lib\shift-rules.ps1` | 班別代碼與值班規則 |
| `tasks\overtime.ps1` | 背景工作：讀班表、值班加班申請 |
| `modules\*.ps1` | 各頁面（檔名數字決定選單順序） |
| `make-shortcut.ps1` | 建立捷徑 |
| `update.ps1` | 從 GitHub 更新、還原上一版、每天自動更新排程 |

## 新增功能

在 `modules\` 放一個 `.ps1`，用 `New-Page '名稱' $Icon.xxx` 建立頁面。需要操作出勤系統的工作寫在 `tasks\`，在頁面裡用 `Start-Task` 於背景執行（進度以 `TYPE<TAB>內容` 一行一筆回報）。

## 班別代碼

| 代碼 | 意義 |
| --- | --- |
| 9076 | 全天班 07:30–17:30（隔天是 906/908 就代表當天值班） |
| 908 | 值班隔天，中午下班 08:00–11:30 |
| 906 | 值班隔天，早上下班 |
| 100 / 102 | 休假，不用打卡 |
